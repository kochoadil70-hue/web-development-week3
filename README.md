# Monthly Budget Tracker

This project is a polished budget tracking dashboard created to improve the visual identity of the app using CSS. The design focuses on a clean, modern look, consistent color use, readable typography, and better spacing through the CSS box model.

## What the project includes

- A clear page header and summary cards for monthly budget, spent amount, and remaining balance.
- A styled add-expense form with labeled inputs and a primary action button.
- A readable expense table with alternating row colors, strong table headers, and spacing for easy scanning.
- Consistent typography using Google Fonts and a cohesive palette throughout the app.

## Files in this project

- `index.html` – structures the page layout and content.
- `style.css` – contains all styling, layout, colors, typography, and table/form design.

## Design choices

- Color palette: deep navy, blue accents, warm orange highlights, and soft neutral backgrounds for a professional feel.
- Typography: Poppins for headings and Inter for body content to create a visual hierarchy.
- Layout: distinct cards for the page header, expense form, and table, all separated with padding, borders, and rounded corners.

## How to view the project

Open `index.html` in a browser to see the app.
